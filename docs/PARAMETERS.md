### Particles

Painterly precipitation and airborne particles: rain, snow, sand, dust, dirt.

*Host:* `DOMAIN` – the object's own mesh is the domain/shape.

*Create buttons:* **Rain** (Rain), **Snow** (Snow), **Sand** (Sand), **Dust** (Dust Motes), **Dirt** (Dirt)

*Presets:* `Rain`, `Storm`, `Snow`, `Blizzard`, `Sand`, `Dust Devil`, `Dust Motes`, `Dirt`

*Materials:* Particles (brush: Streak)

| Loop Frames | int | 0 | 0 … 100000 | Make the animation loop seamlessly every N frames (0 = no loop). Periods are quantised so every cycle fits the loop |
